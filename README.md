# By Lely Media

Site de Lea Mercier, vidéaste d'évènements en Île-de-France et en Savoie.

- `index.html` : la page du site (HTML, CSS et JavaScript dans un seul fichier)
- `favicon.svg` : l'icône de l'onglet
- `og.jpg` : l'image d'aperçu quand le lien est partagé
- `lea.jpg` : portrait de la section À propos
